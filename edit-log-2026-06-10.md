## Shroomling — potion-colour "bubble" render layer (feature request)

Added a collar-style overlay layer that re-renders the Shroomling with the existing
`shroomling_bubble.png` mask tinted by the colour of the potion effect it currently carries.

- `entities/tameable/ShroomlingEntity.java` — new public `getSporeColor()`: returns the packed RGB
  of the carried spore effect (`buildSporeEffect().getEffect().getColor()`), derived from the synced
  `SPORE_EFFECT` index so it is valid client-side; falls back to white (`0xFFFFFF`) when there is no
  effect.
- `client/layer/ShroomlingBubbleLayer.java` (new) — a GeckoLib `GeoRenderLayer` modelled on
  `ScarecrowCollarLayer`. When the entity isn't invisible it `reRender`s the baked model with
  `RenderType.entityTranslucent(textures/mobs/shroomling/shroomling_bubble.png)`, tinted by
  `getSporeColor()` (unpacked to r/g/b), at the entity's own packed light.
- `client/renderer/entity/ShroomlingRenderer.java` — `addRenderLayer(new ShroomlingBubbleLayer<>(this))`
  in the constructor; added the import.

Why: requested — surface each Shroomling's carried potion effect visually as a coloured bubble.
Verified with `gradlew compileJava` — BUILD SUCCESSFUL (only the pre-existing JEI deprecation warning).

### Shroomling bubble — brightness/saturation boost (follow-up)
- `client/layer/ShroomlingBubbleLayer.java` — the bubble now renders at `LightTexture.FULL_BRIGHT`
  (glows regardless of world light) and the tint is pushed for vibrance: saturation ×1.8 (channels
  pushed away from luminance grey) then brightness ×1.3, clamped to [0,1]. Makes the muted vanilla
  effect colours read as vivid bubbles. Why: requested brighter / more saturated bubble.
  `gradlew compileJava` — BUILD SUCCESSFUL.

### Shroomling bubble — switched to emissive eyes glow (follow-up)
- `client/layer/ShroomlingBubbleLayer.java` — render type changed from `entityTranslucent` to
  `RenderType.eyes(shroomling_bubble.png)`: emissive, full-bright, additive blending, so the bubble
  actually glows/blooms. Dropped the separate brightness multiplier (additive provides it) and kept
  the ×1.8 saturation boost so colours stay a vivid hue instead of washing out to white.
  Why: requested the eyes/glow look. `gradlew compileJava` — BUILD SUCCESSFUL.
